Applied Research & Machine Learning

Research-grade work spanning medical imaging, computer vision, and constraint-aware recommendation systems — the DSCBAM-Net work is a peer-reviewed IEEE publication.

Brain Tumor Classification — DSCBAM-Net
Published · IEEE EICT 2025
Problem
Subtle inter-class variation between tumor types under limited clinical compute budgets
Dataset
Two clinical brain MRI tumor datasets (glioma / meningioma / pituitary / no-tumor)
Model
Lightweight CNN + Grouped Depthwise-Separable CBAM (channel + factorized depthwise spatial attention)
Result
97.43% acc / 0.9972 AUC (dataset 1) · 95.96% acc / 0.9951 AUC (dataset 2), fewer params than transfer-learning baselines
Pipeline note: a preprocessing gate classifier (MRI vs. non-MRI, ~98.9% val. accuracy) filters invalid inputs before they reach DSCBAM-Net.
Paper (IEEE) Code
